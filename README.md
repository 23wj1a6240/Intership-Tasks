# Smart Home Risk Checker

Prototype for the college assignment **"The Smart Home Privacy Problem"**
(Computer Science and Cyber Security).

**Author:** K. Naveen | **Roll No:** 23WJ1A6240

## What it does
An interactive checklist for a family using a smart camera, voice assistant,
connected door lock, and smart TV, plus the home network. Tick the protections
already in place and the page updates:

- a device-risk matrix (High / Medium / Low per device)
- a prioritized "Do these next" list (Critical > High > Medium > Low)

Risk levels are a simple estimate based on unmet weighted protections.
This is a learning prototype, not a security audit.

## Run it
No build step or dependencies. Open `index.html` in any modern browser.

## Publish with GitHub Pages
Repository **Settings > Pages > Deploy from branch > main / (root)**.
